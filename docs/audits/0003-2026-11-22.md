- R35, `docs/design.md:235-236`: "Prompts: the full question on one line, with the possible answers and the default spelled out in words". The same requirement forbids information "by colour or symbols alone".

- This is about what the tool should show; the choice is the owner's. Either the documents describe the question without fixing that form (answers and default in words, translated per R27), or R35 is relaxed.
